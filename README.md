Jogo da forca desenvolvido para a disciplina de Programação Web da Universidade Federal de Lavras (UFLA).

## Objetivo

Descobrir o nome do animal sorteado antes de completar seis erros.

Os jogadores se alternam entre as rodadas e recebem 1 ponto quando descobrem corretamente a palavra.

## Regras

- Um animal é sorteado aleatoriamente a cada rodada.
- Os animais não se repetem durante a mesma partida.
- Cada jogador pode errar no máximo 6 letras.
- Ao descobrir a palavra, o jogador recebe 1 ponto.
- Ao final da rodada, a vez passa para o outro jogador.
